# DNSC6330-10-Individual-Week-3-Compas-analysis-python

## 1. Purpose of the Analysis
This project evaluates fairness in a COMPAS-based risk prediction model. The goal is to examine potential disparities across race and sex using metrics based on the Lecture 3 materials. (for example:AIR, ME, SMD, and error rates)

## 2. Python Libraries Used
- pandas
- numpy
- matplotlib
- scikit-learn
- statsmodels
- solas-ai-disparity

## 3. Instructions to Reproduce the Results
1. Install required libraries:
   pip install pandas numpy matplotlib scikit-learn statsmodels solas-ai-disparity
2. Open the Jupyter Notebook.
3. Run all cells from top to bottom.
4. The output will include:
   - AIR, ME, and SMD calculations
   - Intersectional analysis (race × sex)
   - FPR and FNR disparity analysis
   - Visualization of error rate disparities
